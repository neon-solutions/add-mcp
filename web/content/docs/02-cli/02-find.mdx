---
title: find / search
description: Search MCP registries from the terminal and install a selected match.
---

Search configured MCP registries by keyword and install a result interactively. `search` is an alias for `find`.

```bash
npx add-mcp find [keyword] [options]
```

## Examples

```bash
# Search for servers by keyword and choose one interactively
npx add-mcp find vercel

# Browse servers without a keyword
npx add-mcp find

# Use the search alias (same as find)
npx add-mcp search notion

# Install a found server globally to a specific agent without prompts
npx add-mcp find neon -a claude-code -g -y

# Install to project-level Cursor without prompts and ignore its config
npx add-mcp find github -a cursor -y --gitignore
```

## Options

| Option                  | Description                                                           |
| ----------------------- | --------------------------------------------------------------------- |
| `-g, --global`          | Install to user directory instead of project                          |
| `-a, --agent <agent>`   | Target specific agents (e.g. `cursor`, `claude-code`). Repeatable.    |
| `-n, --name <name>`     | Server name override (defaults to the selected catalog entry name)    |
| `-y, --yes`             | Skip confirmation prompts                                             |
| `--auto-approve`        | Auto-approve MCP tool calls for supported agents (Codex, Claude Code) |
| `--approve-tool <tool>` | Tool to auto-approve (repeatable; implies `--auto-approve`)           |
| `--all`                 | Install to all agents                                                 |
| `--gitignore`           | Add generated config files to `.gitignore`                            |

Without explicit `-a` selections, `--all` selects global-only agents too, so an all-agent install uses global scope and ignores `--gitignore`. Explicit agents take precedence; scope is determined after any incompatible agents are skipped. Use project-capable agents as above to generate project configs ([2.6.1 CLI source](https://github.com/neon-solutions/add-mcp/blob/v2.6.1/src/index.ts)).

## Transport selection

Transport is inferred from registry metadata. The CLI prefers HTTP remotes when available and only falls back to SSE when HTTP isn't available for the selected install context. When a server offers both remote and stdio package options, interactive mode lets you choose one (remote is the default); with `-y`, it auto-selects remote.

If a selected remote server defines URL variables or header inputs:

- required values must be provided,
- optional values can be skipped with Enter,
- with `-y`, placeholders are inserted (for example `<your-header-value-here>`).

## Registries

The first `find`/`search` run saves the default [add-mcp registry](/docs/registry) to `~/.config/add-mcp/config.json` and reuses it on every subsequent search. See the [registry docs](/docs/registry) for editing, adding, or hosting registries.

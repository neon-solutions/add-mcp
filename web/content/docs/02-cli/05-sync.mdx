---
title: sync
description: Synchronize server names and installations across agents.
---

Synchronize server names and installations across all detected agents. Servers are grouped by URL or package name, and each group is unified to the shortest server name. Servers with conflicting headers, env, or args across agents are skipped with a warning. `unify` is an alias for `sync`.

```bash
npx add-mcp sync [options]
```

## Examples

```bash
# Sync project-level configs (interactive confirmation)
npx add-mcp sync

# Sync without prompting
npx add-mcp sync -y

# Sync global configs
npx add-mcp sync -g -y
```

Unreadable config files are reported and skipped for every agent sharing that file; the command exits nonzero. Sync also refuses to overwrite a different OpenCode server already using the destination name ([release changelog](https://github.com/neon-solutions/add-mcp/blob/v2.6.1/CHANGELOG.md)).

## Options

| Option         | Description                            |
| -------------- | -------------------------------------- |
| `-g, --global` | Sync global configs instead of project |
| `-y, --yes`    | Skip confirmation prompts              |
